# Figure captions

These figures compare the three predeclared parameter configurations, not a new Monte Carlo ensemble. The same saved vector is applied to both models. No unsafe or failed case is removed from the tables. An absent trajectory, if any, must be read with the run accounting rather than interpreted as zero response.

1. [August 2019 hydrographs](plots/01_historical_20190825T0200Z_hydrographs.png). Columns show the three existing configurations; rows show river stage and outlet discharge. Solid lines are the wetland model and dashed lines the no-wetland model. Colors distinguish the original no-prefix reference and 24 h/72 h continuous conditioning. Time zero marks the original event start; negative times retain all antecedent outputs, including the assumed initial river peak. The original saved reference appears only from time zero. Vertical scales differ between parameter columns; compare labeled values, not apparent visual amplitude across panels. Thus an event-only peak can differ even while the full extended horizon remains dominated by its earlier initial condition.

2. [August 2024 hydrographs](plots/01_historical_20240804T1500Z_hydrographs.png). Same definitions and all three configurations. The 72 h prefix contains recorded rainfall; the 24 h prefix does not. Differences therefore reflect both the extra forcing history and the longer evolution from assumed initial states, not conditioning duration alone. The unchanged 144 h event inputs are common to all three runs.

3. [Event-window paired outcomes](plots/02_paired_event_outcomes.png). Differences are no wetland minus wetland for maxima and cumulative outlet volume within the original 144 h window. All windows include their own initial endpoint. Positive peak differences indicate wetland attenuation; a negative volume difference means the wetland system discharged more water over that window, which can coexist with lower peaks. Connecting three conditioning durations is a comparison aid, not a fitted dose-response curve or evidence of equilibration. Full extended-horizon metrics remain separately available in the tables.

4. [Actual gate histories](plots/03_gate_histories.png). Colors denote prefix duration; solid/dotted styles denote Gates 1/2. Both models are overlaid, with the no-wetland line partially transparent. Their equality is checked numerically, not inferred from overlapping pixels. Every trace is a state-dependent output of the same unchanged policy; different conditioning durations can change its subsequent operation. The event boundary has no reset of opening, latch memory or controller clock.

5. [Whole-system storage contrasts](plots/04_storage_contrasts.png). Each line shows wetland-system storage minus no-wetland-system storage for one existing vector at the original event start or final endpoint. The no-prefix event starts with the additional accepted 5,500 m³. Conditioned event starts instead use all carried storages. These contrasts include groundwater and river as well as wetlands; they do not identify which water originated in the initial wetland stock or estimate a fraction of tagged initial water retained.

6. [Joint meteorological inputs](plots/05_weather_inputs.png). Both events are shown with the actual 72 h prefix; shading marks the prefix, a dashed line marks −24 h and a solid line the original event start. Rainfall and solar interval means retain their conservative hourly steps. Temperature and wind retain the documented midpoint interpolation and endpoint holds. The separate 24 h run has its own first-half-hour hold at −24 h, so its prefix interpolation is not claimed identical everywhere to this 72 h curve. The original event mapping is identical in all cases. [Detailed caption and provenance](forcing/weather_figure_caption.md).
